# Operator preferences

> Adapter file for harnesses that read `AGENTS.md` (Codex CLI, and the growing set of tools adopting the convention). The canonical source is [`../principles/working-style.md`](../principles/working-style.md).
> Keep this a pointer. If your harness does not support includes, symlink this file to the canonical doc instead of copying it:
> `ln -sf ../principles/working-style.md AGENTS.md`

The operative rules are in `../principles/working-style.md`:

- **Decision bias** — default to action, not confirmation.
- **Canonical-pattern-first** for infrastructure.
- **Worktree isolation** for parallel sessions.
- **Prose-voice** tasks load the voice guide first.
- **Never fabricate** the author's interior state.
- **Secret handling** — secrets manager, check existing first.

Read that file in full before operating in a repo that links here.
