# Operator preferences

> Adapter file for Gemini CLI, which reads `GEMINI.md` by convention. The canonical source is [`../principles/working-style.md`](../principles/working-style.md).
> Gemini CLI does not resolve `@include` directives the way Claude Code does — so either symlink this file to the canonical doc, or paste its contents here and re-sync on change. Symlink is preferred:
> `ln -sf ../principles/working-style.md GEMINI.md`

The operative rules are in `../principles/working-style.md`. Read that file in full before operating.

The principles are harness-agnostic by design — nothing in them assumes Claude Code. Decision bias, canonical-pattern-first, worktree isolation, and the prose/secret conventions apply identically whichever model is driving.
